# Cyclistic Bike-Share Case Study

## Overview
Data analysis project examining differences in bike usage between casual riders and annual Cyclistic members. The analysis uses Divvy trip data from the full 2025 calendar year and contains over 5.5 million rides.

## Data Source
This project uses [Divvy trip data](https://divvybikes.com/system-data), provided by Motivate International Inc. under its [Data License Agreement](https://divvybikes.com/data-license-agreement). Raw data files are not included in this repository — see the notebook's Author's Note for download instructions.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn

## Requirements & How to Run
Install the required packages:
```
pip install pandas numpy matplotlib seaborn jupyter
```

To reproduce the analysis:
1. Download the 2025 Divvy trip data (see Data Source above)
2. Place the monthly CSV files in the same directory as the notebook
3. Run `jupyter notebook cyclistic-bike-share-case-study.ipynb`

## Main Question
How do annual members and casual riders use Cyclistic bikes differently?

## Key Findings
- Casual riders take longer rides.
- Members show stronger commuting patterns.
- Casual riders are more active on weekends.
- Casual usage is more seasonal.

## Recommendations
1. Launch membership campaigns before the summer season.
2. Focus promotional efforts on weekends.
3. Target frequent casual riders with personalized membership offers.
